SCSS → CSS · NPM · CLI

Viết gọn bằng Sass.
Biên dịch bằng CLI.

Một dự án nhỏ để thực hành cài đặt Sass qua npm, biên dịch SCSS, chạy chế độ theo dõi và xử lý nhiều entry point cùng lúc.

BIÊN DỊCH TOÀN BỘ THƯ MỤC npm run build scss/ → css/
Hai file SCSS đầu vào · Hai file CSS đầu ra

THỬ NGHIỆM THỰC TẾ

Cùng một project, nhiều cách chạy.

Chạy các lệnh bên dưới trong thư mục dự án sau khi cài dependencies.

01 / CÀI ĐẶT

npm install

Cài Dart Sass vào project như một dev dependency. Kiểm tra phiên bản Node.js, npm và Sass CLI trước khi bắt đầu.

node -v · npm -v · npx sass --version
02 / THEO DÕI

npm run watch

Sass CLI theo dõi thư mục SCSS và tự cập nhật các file CSS khi bạn lưu thay đổi.

npm run watch
03 / NHIỀU FILE

scss/ → css/

Biên dịch mọi entry point trong thư mục nguồn sang cấu trúc CSS tương ứng chỉ với một lệnh.

npm run build

CẤU TRÚC ĐẦU RA

SCSS được biên dịch,
trình duyệt đọc CSS.

scss/
├── _tokens.scss
├── _mixins.scss
├── main.scss
└── cards.scss

css/
├── main.css
└── cards.css

TỪ FILE CARDS.SCSS

Một vài thẻ đã được biên dịch.

VARIABLESMàu sắc dùng chung

Một bảng màu, nhiều thành phần.

MIXINSQuy tắc có thể dùng lại

Viết một lần, áp dụng nhất quán.

NESTINGCấu trúc SCSS rõ ràng

Chọn lọc dễ đọc, CSS đầu ra chuẩn.
